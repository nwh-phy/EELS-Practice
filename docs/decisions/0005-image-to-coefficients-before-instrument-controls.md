# 0005 — 先反演有效像差，再映射仪器控制

状态：离线基线已实现；真实 UHEMRS 标定、训练和硬件验收待工作环境完成。

## 依据

用户希望由初始二维光斑给出 Nion UHEMRS 的可调参数组合。参考照片只显示 20 参数 AlexNet 回归结构，没有给出数据预处理、损失、控制名、单位、量程或响应矩阵。公开的 Guo–Lupini 工作包含 Nion Swift 采集和像差测量源码，但其代码也提醒具体控制名需在目标仪器核对，不能直接作为本机控制配置。

当前模拟器输出 20 项 `Dij` 能量等效系数。它积分掉了对称孔径坐标 `u`，所以单图在“全部奇数 `u` 次项同时反号”下严格不变；另外也不能排除真实仪器中的其他耦合或简并。直接把单图回归结果写入硬件既没有唯一性保证，也没有控制标定依据。

## 决定

- 网络第一阶段只回归 20 项有效系数补偿 `ΔE`，不声称它们是 Nion 执行器值。
- 同时保留单图模式和推荐的已知探测双图模式。单图训练使用对称感知损失并报告等价答案；双图用一个已知可逆探测打破当前模型中已证明的全局反号对称。
- 架构参考照片中的五段特征提取与 `9216 → 2048 → 512 → 20` 回归头；不声称复现未公开的训练实现。
- 真实控制层使用目标仪器测得的局部响应 `ΔE = JΔc`。仓库只提供读取审核后响应矩阵、求带正则与单步限幅的 `Δc` 建议并报告预测残差的离线工具。控制名、单位、探测幅度、限幅、回滚和 interlock 由仪器负责人提供并单独审核；不实现 Nion 写控制代码。
- PyTorch 是可选的工作站依赖，与基础模拟器隔离。当前小容量 Mac 不安装 PyTorch、不生成正式数据集、不训练权重。

## 代价与回退

两层方案需要额外标定，但可以分别验证图像反演误差和执行器映射误差，也允许维护后只更新响应矩阵。双图多一次采集和安全探测步骤，但比把模拟对称性当成可学习信号可靠。停止使用 ML 工具不会改变现有模拟器、桌面版或练习流程；当前代码没有任何仪器连接或自动执行路径。
